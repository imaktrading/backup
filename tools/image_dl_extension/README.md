# 商品画像ダウンローダー (Chrome拡張)

商品ページでツールバーのアイコンを押すと、そのページの商品画像を一括DL。
Shopify(Clock House 等)は公開JSONから原寸を取得するので**右クリック禁止でも取れる**。

## インストール(1回だけ)
1. Chrome で `chrome://extensions` を開く
2. 右上「デベロッパー モード」を ON
3.「パッケージ化されていない拡張機能を読み込む」→ このフォルダ
   `C:\dev\iMak\tools\image_dl_extension` を選択
4. ツールバーにアイコンが出る(ピン留め推奨)

## 使い方
- 商品ページを開く → アイコンをクリック → 自動で全画像DL
- アイコンに緑のバッジで枚数(例「4」)、0枚や失敗は赤

## 保存先 = デスクトップにするには
拡張は Chrome の「ダウンロード場所」配下に保存します(サブフォルダ `images_<商品handle>/`)。
**デスクトップに保存したい場合**、どちらか:
- Chrome 設定 → ダウンロード → 保存先 を **デスクトップ** に変更(全DLがデスクトップ配下に)
- または「ダウンロード前に各ファイルの保存場所を確認する」を ON(都度デスクトップを選ぶ)

→ すると画像は `デスクトップ\images_<handle>\01.jpg ...` に入る。

## 対応
- **graniph** (`/item-detail/<9桁品番><3桁カラー>`): 商品画像だけを URL 構造で特定 (2026-08-08 追加)
- Shopify(`/products/<handle>.json` がある店): 原寸・全枚数
- それ以外: 表示中の画像(<img> srcset 最大 + 背景画像)を収集(解像度200px以上)

### graniph の実測メモ (2026-08-08)

```
商品画像 https://cf.graniph.com/images/item/product_image/<9桁品番>.<3桁カラー>.-_<n>.jpg
原寸     1125 x 1575  ← これが最大
枚数     _1 〜 _10 (この商品の場合)。_11 は 403
保存先   images_graniph_<品番+カラー>/01.jpg …
```

- **専用ルールにした理由**: 汎用フォールバックだと 12件拾い、うち2件が
  クーポンバナー (`/images/common/...`) とフィード画像 (`/images/feed/...`) だった。
  品番+カラー一致に絞ると **商品10枚ちょうど**になる (実測)
- **色違いは拾わない**。ページURLのカラーコードと一致するものだけ (混ざると誤出品)
- **大きい版を探しに行かない**: `_l` / `_org` / `product_image_l` / `?width=2000` は
  全部 403 を実測済み。1125x1575 が原寸
- 0枚なら赤バッジで 0 と出る。**バナーで埋めない** (取れたと誤解しないため)
