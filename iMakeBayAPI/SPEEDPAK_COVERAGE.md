## 3. 制約(PDF 記載・出品設計に直結)

- **EU 向けは €150 以下**(IOSS 制度準拠。超えると別扱い)
- 英国向けは £135 以下(IOSS)
- 豪州向けは同一バイヤー同日 1,000 AUD 以下(GST)
- 最大貨物重量 68kg / 目的国に配達できない場合は**転送も返送もされず破棄**

## 4. 我々の現状と 7/24 問題(2026-07-20 棚卸し実測)

日本郵便が **2026-07-24 から EU 全域の引受停止**([[jp_post_eu_suspension_20260724]])。

| 区分 | active | 在庫あり(実露出) | 状態 |
|---|--:|--:|---|
| P14+(rate table 無) | 748 | **257** | 全EU が日本郵便 DDU = **発送不能** |
| P01-P13(rate table `5296250010`) | 468 | **248** | SpeedPAK 8か国のみ・**残り19か国が不能** |
| Free | 489 | 0 | 全て在庫切れ = 当面無害 |

- **rate table `5296250010` は 36 ポリシーが共有**(Account API `fulfillment_policy` で確認)
  → **表 1 枚に 19 か国を追加すれば P01-P13 の 468 件が一斉に解決**
- rate table 無しは **50 ポリシー**(うち実出品ありは 28)
- **rate table は eBay UI 専用・API 編集不可**(読取も `sell/account/v1/rate_table` は空を返す)= 手作業
