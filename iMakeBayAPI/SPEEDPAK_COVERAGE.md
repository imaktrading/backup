## 3. 制約(PDF 記載・出品設計に直結)

- **EU 向けは €150 以下**(IOSS 制度準拠。超えると別扱い)
- 英国向けは £135 以下(IOSS)
- 豪州向けは同一バイヤー同日 1,000 AUD 以下(GST)
- 最大貨物重量 68kg / 目的国に配達できない場合は**転送も返送もされず破棄**

## 4. 我々の現状と 7/24 問題(2026-07-21 ユーザー確定スコープ)

**★停止は「特定8カ国 × €150未満(BtoC)」のみ。全EU停止ではない**([[jp_post_eu_suspension_20260724]])。
- 特定8カ国 = **独・仏・奥・白・丁・芬・葡・ルクセン**(= 元から SpeedPAK の8カ国と同一)。
- それ以外(他19 EU国 / 8カ国でも €150以上) = **日本郵便 継続**。
- €150超は SpeedPAK Expedited(FedEx)でも送れる(€150 上限は **Economy 版=独 のみ**の IOSS 制約。FedEx版に€150記載なし)。

### 棚卸し実測(2026-07-20)と対応状況
| 区分 | active | 在庫あり | 停止スコープでの状態 |
|---|--:|--:|---|
| P01-P13(rate table `5296250010`) | 468 | 248 | ✅ 8カ国 €150未満を SpeedPAK で**カバー済**(rate table は EU27 全て SpeedPAK) |
| P14+(rate table 無) | 748 | 257 | ほぼ全て €150超 → 8カ国でも日本郵便継続=**問題なし**。※≤€150 が **5件**だけ残穴(8カ国宛てなら要手当) |
| Free | 489 | 0 | 在庫切れ = 無害 |

- **rate table `5296250010` は 36 ポリシー共有**。現状 **EU27 全て SpeedPAK 割当済**(実スクショ 2026-07-21 確認)= 実露出(8カ国€150未満)は解決済み。
- **rate table は eBay UI 専用・API 編集不可**(読取 `sell/account/v1/rate_table` も空)。ただし **既存表をポリシーへ貼付**は Account API `updateFulfillmentPolicy` で可能か要検証。
- 残穴の5件(P14+ ≤€150)は P01-P13 系ポリシーへ移すか rate table 貼付で塞げる(任意・軽微)。

### rate table 現状(2026-07-21 スクショ `iMak_EU_DDP_Common`)
- Economy $17: ドイツ / Expedited $20: 仏・伊 / Expedited $24: ルーマニア / Expedited $18: 他EU一括(墺白丁愛芬希洪…西蘭波葡瑞典等)
- **EU27 全カバー**(必要な8カ国+余剰19カ国。余剰は害なし=SpeedPAK DDP の方が€3/VAT をクリーンに処理)。
