商品URL:
<ここに UNIQLO/GU の商品URLを貼る>

守ること:
- サイズ実寸は推測せず `python C:\dev\iMak\iMakMercari\uniqlo_size_fetch.py {productId} {colorCode} {sizeCode}`
  で全サイズ(XS〜3XL等)を公式から取得して使う(端サイズを欠かさない)。
- タイトル ~80字SEO / Material は公式composition。
- Item Specifics は eBay出品フォームの項目順で全項目を出力し、🔴 は product 固有の変更点だけ
  付ける(Color / Fit / Theme=Anime / Pattern=Graphic Print / Country of Origin。カテゴリに
  Character 欄があればそれも)。残りは固定テンプレ値(Runbook §5)。Women's Tops(53159)は
  Character 欄が無いのでキャラはタイトルで担保。
- Color は**公式の色名(colors[].name)をそのまま使う**。見た目で Light Blue 等に変えない(公式=Blue なら Blue)。
- バリエーション出品(軸=Sizes)。既存例listingの形式を踏襲。
- 商品説明(Description)は **コピペ用の完成HTMLをデスクトップに .html で出力**する
  (`C:\Users\imax2\OneDrive\デスクトップ\` に。テンプレ踏襲・コラボ紹介/実測表/色/サイズを差替)。
- **Sheerness(透け感)を Description に必ず含める**。値は**公式API `result.designDetail` の「透け感: 〇〇」から取る**
  (なし→None / ややあり→Slight / あり→Yes)。推測禁止。designDetail には「トップスフィット」も入っていてFit判定にも使える。
- 既存listingの改変を頼む場合は eBay item number も併記する。
