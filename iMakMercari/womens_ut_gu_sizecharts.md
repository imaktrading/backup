## 運用メモ
- eBay Description の Size 欄: 身丈=Length / 身幅=Chest(pit-to-pit) / 肩幅=Shoulder / 裄丈=Sleeve。
- 型判定は商品名の「/XXフィット」語で自動分岐（標準=表記なし / オーバーサイズ / リラックス / ミニ / ショート / ボクシー / ボクシー・シアー）。
- GU グラフィックTは多くユニセックス（男女共通チャート可）。フィットは標準/ボクシーの2択。
- 寸法は公式JSON APIに無く、公式サイズ表（S3ガードでbot不可）を実ブラウザで開いてキャプチャ→読取した実測値。
