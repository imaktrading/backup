# CPSC / GCC 調査レポート (2026-06-17 / 公式source 裏取り済)

Japan発 eBay cross-border DROP-SHIP(米法人なし・<$800中心・DDP・Japan Post/express)向け。
HQ が WebSearch/WebFetch で公式source(Federal Register / eCFR / CPSC / CBP)照合。

## Q1. eFiling(証明書の電子提出)
- 施行 **2026-07-08**(FTZ経由 2027-01-08)。Federal Register 2025-01-08 (2024-30826)。
- 義務者 = **輸入者(importer of record)**、実務は通関業者が ACE で entry 時送信。marketplace seller 自身ではない。
- 郵便/informal/dropship の細部は CPSC公式FAQ 403で未取得 → **要法務+配送業者確認**。

## Q2. de minimis 廃止 ★最大の変化
- EO 14324、**2025-08-29 施行**、全世界・価格/原産/輸送手段(郵便含む)問わず免税廃止。
  Federal Register 2025-09-02 (2025-16802)。
- = iMak の <$800 小包も通常 entry → 関税 +(CPSC規制品なら)eFiling 適用。

## Q3. 免除衣類の GCC = 実質不要
- 1610.1(d) は「試験免除」(規格は適用)。CPSC 執行裁量(2016-03-25 施行、FR 2016-04533):
  **試験免除の大人用衣類は GCC 未発行を摘発しない**。
- = Montbell/UNIQLO/GU 大人用 = GCC 自作 実質不要(難燃実体適合は必要)。Advisor の前提覆る。

## Q4. 「15歳以上」表示は決定打でない
- 児童製品(≤12)判定は4要素総合(eCFR 1200.2)。メーカー表示は1要素。子供への primary appeal
  (装飾/テーマ/キャラ)があれば児童製品になりうる。
- = フィギュア/Tomica は概ね可、Pokemon系 子供連想強は 15+ だけでは不十分の残存リスク。

## Q5. GCC 発行主体 + 7要素
- 海外製は輸入者が発行。7要素 = 16 CFR 1110.11(製品ID/該当規制/輸入者名住所電話/記録保持者連絡先/
  製造日場所/試験日場所/第三者ラボ(児童製品))。
- 転売者が製造者証明書に依拠できるか = 未確定 → 要法務。

## bottom line
1. 本丸は GCC でなく **de minimis 廃止**(全小包に関税+通関)。最大論点はコスト/通関フロー。
2. eFiling は輸入者(通関業者)義務。DDP郵便 dropship の **IOR が誰か / 業者の eFile 実務**が核心の未確定。
3. 大人用衣類 GCC 自作は実質不要(執行裁量)→ Phase2 大半不要かも。
4. 玩具は 15+ で概ね可、Pokemon系のみ要注意。

## 要法務確認
- DDP郵便の IOR + eFile 実務 / 免除衣類で eFile 対象物の有無 / 転売者の証明書依拠可否 /
  Pokemon系の児童製品4要素判定。
