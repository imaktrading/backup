# 出品くん Console — 変更の記録

版の数え方は `version.py` を見ること。**1.0 = 旧 出品くん (control_panel.py) の全ボタンが
新画面で押せるようになった時**。それまでは 0.x で、旧パネルと併用する。

旧 出品くん (control_panel.py) には版を振らない (移行の間ずっと残す・触らない)。

## 0.2.0 — 2026-09-16
- 合意した見本の形に組み直した: ページ分け (今日やること / 新規出品 / 在庫メンテ / 分析・棚 / 定期)
- 補URL・再仕入れを **商材 × 段階** の格子に
- 「担当」「実行ログ」の常設欄を外した (ログは実行中・直後だけ下から出す)
- 定期タブ = Windows のタスクの前回結果・次回予定
- 版と移行状況を画面に出した (「版・移行」タブ)。押せないボタンは**理由付き**で並ぶ

## 0.1.0 — 2026-09-15
- 最初のホーム画面。件数・棚割り・夜間の結果を読む
- 押せるのは後処理の無いボタンだけ (それ以外は「今の出品くんで」と出す)
