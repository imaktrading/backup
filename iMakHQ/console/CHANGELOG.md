# 出品くん Console — 変更の記録

版の数え方は `version.py` を見ること。**1.0 = 旧 出品くん (control_panel.py) の全ボタンが
新画面で押せるようになった時**。それまでは 0.x で、旧パネルと併用する。

旧 出品くん (control_panel.py) には版を振らない (移行の間ずっと残す・触らない)。

## 0.7.8 (2026-09-19)

- **商材をカードの1番目に出す** (ユーザー「PSA関係なのか、くじ関係なのか、UT関係なのかが
  いまいち分かりにくい」)。PSA / UT / くじ / G-SHOCK を色付きの札で先頭に置き、
  まとまり (補URL ③ 等) はその次にした。
- **オファーを今日やることに出す** (ユーザー「重要だからTOP画面に」)。
  在庫メンテの枠の先頭。件数 (受信中のオファー) も旧パネルと同じものを出す。

## 0.7.8 (2026-09-20)

- **よく売れているカードの一覧**を「分析・棚」に追加 (ユーザー要望)。
  何のカードか / 何個売れたか / 実売の中央値 / うちの値段 / 差 / **出品済か未出品か**。
  絞り込み: 全部 / 未出品だけ / 出品済だけ / 値上げできる。
  中身は `tools/market_ledger.build_cards` が唯一の口 (CSV と同じものを見る)。
  今のところ 175種類 — 出品済46 / 未出品129。

## 0.7.7 (2026-09-19)

- **補URL の「入れ替え」が今日やることに出ない** のを直した (ユーザー指摘)。
  「補充」と「入れ替え」は別の行に対する別の作業で順番の関係が無いのに、同じ ③ として
  1本の順番に入れていたため、補充が0件になるまで隠れていた (実測: 補充88件 / 入れ替え17件)。
  この2つだけ別の流れとして数える (①→②→③ の順番待ち自体は今までどおり)。

## 0.7.6 (2026-09-19)

- **オファーの件数を出す** (ユーザー「1件来ているけど反映してないね」)。
  在庫メンテの「オファー」の段と目次に、受信中の件数を出す (eBay を1コール)。
- **起動時にログを開かない** (ユーザー要望)。前回の走行の記録が残っているだけで
  開いていた。**今 走っている時だけ**開く。見たい時は右上の「ログを見る」。

## 0.7.5 (2026-09-19)

- **オファーを画面に出した** (ユーザー「出品くんコンソールにオファーがないね」)。
  在庫メンテに「オファー」の段を新設し、`💰 オファー対応` と
  `📣 ミラーに広告・オファーを付ける` を置いた。
  旧パネルでは上段の青ボタン (GUI ハンドラ) だったため、この画面に出ていなかった。
  中身は SCRIPTS に足しただけで、旧パネルと同じ道具を呼ぶ (二重実装しない)。

## 0.7.4 (2026-09-18)

- **上の段 (件数バーと「今日やること / 新規出品 / 在庫メンテ」) を画面に固定** (ユーザー要望)。
  下に長い一覧を見ている間もページを切り替えられる。画面の縦が短い時 (700px 未満) は
  固定しない (固定すると中身がほとんど見えなくなるため)。

## 0.7.3 (2026-09-18)

- **ログは「直前の1本だけ」を扱う** (ユーザー要望)。コピーすると走行が3本ぶん
  入ってしまい、貼って相談する用に使えなかった。
  - 「ログをコピー」= 直前の1本だけコピーする
  - 「🗑 ログを消す」= 前の走行ぶんを消して、直前の1本だけ残す
    (1本しか無ければ全部消す。見出しも一緒に消す)

## 0.7.2 (2026-09-18)

- 「🗑 表示を消す」で **見出し (「失敗: … (returncode=1)」) も一緒に消す**ようにした。
  本文だけ消えて見出しが残り「消えていない」に見えた (ユーザー指摘)。

## 0.7.1 (2026-09-18)

- ログに **「🗑 表示を消す」** ボタンを足した (ユーザー要望)。直前の走行だけを
  コピーして貼りたい、が用途。消しても以降の行は続けて出る。

## 0.7.0 — 2026-09-18
- **「リサーチ」を分析・棚に追加**。市場で何が売れているか (eBay の Research = Terapeak) を
  条件を固定して取り、台帳に溜める。商材 (ポケモン / ワンピース / ドラゴンボール) と
  取るもの (売れた / 出ている) と期間 (既定 90日) を選んで「Research を開く」→
  ブラウザの拡張 `tools/terapeak_grab` で「まとめて取る」→ 戻って「取り込む」「集計を見る」。
  条件は `tools/market_ledger.py` の `PRESETS` が唯一の口で、手打ちしない
  (キーワード `PSA` / CCG Individual Cards / 即決+オファー承諾 / 日本人セラー / 売れた数順)。
  ★ドラゴンボールは市場側で Game が2つに割れているので両方入れる (片方だと半分落ちる)

- サーバの入れ替えで **走行中の作業を道連れにしない** (18:11 に 🤖自動 を落とした実害)。
  入れ替えは restart.ps1 経由にし、走行中は断る

## 0.6.0 — 2026-09-16

  判定は旧パネルと同じ関数を使う。失敗した走行・止めた走行は突き合わせない

- 「ログを見る」ボタン (走っていない時も見返せる)

## 0.4.1 — 2026-09-16
- **棚割りの金額を直した**。統合シートの M列は「現在価格(円) = 仕入元の値」で、US の出品価格ではない。
  それを `$` として合計していたため 棚 $16.84M / TCG +$7.82M と桁が狂っていた
  (実際は 棚 **$176,002** / 予算 $229,661)。金額は **ファネルの US 出品価格**から取る
- 公式在庫シート経由の出品も itemID でファネルと突き合わせて金額に入れた (Tシャツの不明 157→70件)
- ファネルに無い出品は「価格不明 N件」と棚割りに出す。ファネルが1枚も無い時は「金額が出せません」

## 0.4.0 — 2026-09-16
- **止めるボタン**を付けた (ユーザー「確かに停止ボタンがないね」)。走っている時だけ下のログ欄に出る。
  止め方は旧パネルと同じ (子プロセスごと)。止めた走行は「■ 止めました」と締める
- UT 目視の「カタログに無い」: 参考URL欄が薄いままだったのを直し、**複数URL**を受けるようにした
  (スペース / 改行 / カンマ区切り。URL でない字は捨てる)

## 0.3.1 — 2026-09-16

  今日の作業カード・格子のマス・一覧の行は、枠のどこを押しても実行

## 0.3.0 — 2026-09-16
- デスクトップに「出品くん Console」のショートカット (作り直しは make_shortcut.ps1)
- **旧パネルの後処理を共用にした**。走る前のガード (`before_run`) と走った後の後処理 (`after_run`) を
  control_panel から抜き出し、旧パネルも新画面も**同じ関数**を呼ぶ (中身・順番・文言は変えていない)
- これで **新規生成・CSV の後処理があるボタン・入力欄・金額** も新画面から押せる (54/55)
- 入力欄と金額は画面の小窓で聞いてから渡す (旧パネルのダイアログと同じ中身)
- 残る旧パネル専用は **一番くじの新規 (ウィザード画面)** だけ
