# 価格NO-GO廃止 → 既存メンテ「高めレーン」追跡 修正方針

- 制定日: 2026-06-19 / 起案: HQ(ユーザー方針)
- 対象: 全カテゴリの出品可否ロジック(新規 + RESTOCK)
- ステータス: **方針確定。実装は明日の Revise順序修正→通し再走の後に着手**

---

## 背景・原則

これまで **新規出品オンリー**だったため、高すぎる出品が売れずに放置されるのを防ぐ「松葉杖」として
**価格NO-GO(eBay中央値より乖離 > 許容% → 出品見送り=CSV除外)** を置いていた。

しかし:
1. **コストプラス(V8)= 損しない**。出品価格は必ず仕入+利益。
2. **無在庫 = 在庫コストなし**。売れてから仕入れる。
3. → 高めでも出せば「**売れたら利益 / 売れなくても損なし**」= **フリーオプション**。ハード除外は上振れを捨ててる。
4. 判定根拠の **eBay ACTIVE中央値は精度が低い**(売れた価格でなく「言い値」/ 変種混在 / 薄商いでブレる)。実際
   一番くじは `gap_limit_override=10.0` で実質オフ済 = システム自身が median を信用しきってない。
5. **既存メンテに取り組み始めた** = 出した高め出品を後追いで拾って対応できる。→ NO-GO の松葉杖は不要。

**結論: 価格を理由にした出品見送りを廃止。全部出す + 「高め」を既存メンテPDCAで追跡 → アクションに繋ぐ
(Check止まりにしない=spiral-up)。**

---

## 変更内容

### A. 新規出品(TCG / G-shock / Mercari の check_csv)
- **価格NO-GO(乖離>許容→CSV除外)を廃止** → 出品する。
- 代わりに **「高めフラグ」**(乖離%, target_usd, median, 仕入)を立て、既存メンテPDCAへ渡す。
- 緩和/保留 の状態整理: 全部出すなら実質「GO / 高め(出すが追跡)」の2状態でよい。
- **価格自体は V8コストプラスのまま**(値付けロジックは不変)。
- ※ 一番くじは既に実質オフ → 整合。

### B. RESTOCK(PSA再仕入れ照合)
- 2026-06-19 に入れた **仕入高の照合スキップ(`_is_high_cost`)を廃止** → 出品(Revise)。
- 高めは **待ち台帳/既存メンテ**で追跡(End候補と同様、毎回再評価)。

### C. 既存メンテPDCA「高めレーン」(新規構築)
出した高め出品を worklist 化し、アクションに繋ぐ:
- **記録**: itemID / 高さ(乖離%)/ 仕入 / median / 出品からの経過日数 / sell-through
- **アクション**:
  - sell-through監視(一定期間未売 → フラグ)
  - 再探索(仕入元で安く出てないか → 仕入下がれば適正price-revise)
  - 価格ウォッチ(median上昇 → 自動で「適正」に転じる)
  - 長期未売 → 取下げ提案

---

## 残す(廃止しない)= 「正確性」軸の除外は維持
- **dedup**(既出品の重複)= 価格無関係、維持。
- **format / Item Specifics の fail-closed**(誤出品防止)= 維持。
- **catalog-miss skip**(出品の正確性原則)= 維持。
- = **廃止するのは「価格」軸の除外だけ**。「正確性」軸は不変。

---

## 前提・副作用
- **NO-GO撤去と既存メンテ高めレーンはセット**。レーンが動かないと「高め放置」に逆戻り。
- eBay副作用: 売れ残り増 → store の sell-through/検索順位を多少下げうる。**Defect Rate(キャンセル/INAD)には無関係=アカウント健全性は安全**。許容範囲。
- 精度向上の本丸: **ACTIVE中央値 → SOLD(売れた実績)中央値** への切替は別途(価格本丸の続き)。
