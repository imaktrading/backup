## 2. 2026-05-19〜20 で判明した CPaSS US 実態

### 5/19 UT sale ($58.99) の実コスト分解

```
売上手取り (Payoneer 入金 $44.23 × ¥134): ¥5,927
仕入 (UNIQLO UT M): ¥1,990
国際送料 (CPaSS Economy 実績): ¥3,000 弱
Payoneer FX 落ち + 国内送料 + 梱包: ¥418
─────────────────────
利益: ~¥519 (トントン圏内)
```

### CPaSS Economy 公式料金構造 (PDF 2026-03-25 発効)

**合計 = 基本料金 (重量別) + サーチャージ (関税 + 通関 ¥245 + 関税処理 2.1%)**

**基本料金 US 本土48州** (抜粋):
| 重量 | JPY |
|---|---|
| 0.1kg | 1,227 |
| 0.2kg | 1,367 |
| 0.3kg | 1,581 |
| 0.5kg | 2,060 |
| 1.0kg | 3,020 |

**関税**: 商品価格 × HTS 関税率 (カテゴリで大幅に違う)
- Tシャツ HTS 6109/6110: 16-32%
- 時計 HTS 9102: 3.5%
- TCG カード HTS 9504: 0%
- 玩具 HTS 9503: 0%

### 検証結果 (1 ケースのみ)

| 項目 | 現 yaml | CPaSS US 実績 (UT $58.99) | 差 |
|---|---|---|---|
| 送料 (純) | ¥2,000 | ¥1,500-1,600 | +¥400 過大 |
| 関税 | (V5 markup 35% で吸収想定) | ¥1,400 | - |
| 合計 | ¥2,000 + (商品価格 × 35%) | ¥3,000 | - |

`$58.99 × 35% = $20.6 = ¥2,760` → markup 部分 ¥2,049 ≈ CPaSS 関税 ¥1,400 + (純送料余剰 ¥400)

→ **UT $58.99 では markup 35% で関税ほぼ吸収できてる**が、Payoneer FX 落ち / 集荷 / 梱包等で利益消失。

### 高価格商品でのシミュレーション (推定値)

## 4. 争点リスト

### A. V5 markup 35% 一律 の妥当性

| 案 | 内容 | リスク |
|---|---|---|
| A-1 | 35% 維持 (動かない) | データ無しでの動きを避ける、ただし低価格 Tシャツで赤字継続 |
| A-2 | 35% 一律で +α (例 0.50) | 全 US 価格 +15%、売れ行き低下、TCG/玩具で過大過ぎ |
| A-3 | カテゴリ別 markup_rate | yaml 改修必要、根拠データ不足 (HTS 仮値) |
| A-4 | shipping_jpy 一律 +¥1,000 | 非US も +¥1,000 過大 (= 利益側で OK)、二重計上の側面あり |
| A-5 | markup_rate_us=0 + ddp_shipping_tiers 復活 | V4 旧構造、境界 tier 跨ぎバグ再発リスク |

| 案 | 内容 | リスク |
|---|---|---|
